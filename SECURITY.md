# Security policy

This repository is a synthetic local demonstrator. Do not place production,
customer or personal data in it and do not expose its development services to
the internet.

Please report suspected vulnerabilities privately to the project owner through
the contact route on <https://www.intentforce.no/>. Do not include credentials,
personal data or exploit payloads in a public issue. Acknowledgement and fixes
are best-effort because this repository carries no production SLA.

The supported release is the latest `main` commit published identically on the
listed GitHub and GitLab mirrors. Security statements are limited by
[`docs/THREAT-MODEL.md`](docs/THREAT-MODEL.md) and
[`docs/KNOWN-LIMITATIONS.md`](docs/KNOWN-LIMITATIONS.md).
