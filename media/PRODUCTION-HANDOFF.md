# Desktop media handoff

## Deliverables

Produce six narrated exports from the supplied scripts:

1. Norwegian main film, about 8–10 minutes, neutral Finn voice.
2. English main film, about 8–10 minutes, Azure `en-US-AvaNeural`.
3. Norwegian short film, no more than 3 minutes, neutral Finn voice.
4. English short film, no more than 3 minutes, Ava.
5. Norwegian teaser, 20–35 seconds.
6. English teaser, 20–35 seconds.

Also render `assets/social-card-source.svg` to a sharp 1200×630 PNG for Open
Graph/Facebook. Keep the text inside the safe central 1100×560 area.

- Opening or first claim frame: `LITEN, MÅLT DEMO` / `SMALL, MEASURED DEMO`.
- Any AI-created rack/server image: `KONSEPTILLUSTRASJON` / `CONCEPT IMAGE`.
- Actual evidence screens: `TESTET 4. OKTOBER 2026` / `TESTED 4 OCTOBER 2026`.
- End card: `ÅPEN KILDEKODE · APACHE-2.0` / `OPEN SOURCE · APACHE-2.0`.
- Add `REKLAME` / `AD` wherever the final publishing channel requires it.

Do not show or imply a purchased RFID/fingerprint card. Physical credentials
are one possible later upgrade and were not bought, integrated or tested.
