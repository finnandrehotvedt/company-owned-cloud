# Visual shot list

## Real evidence captures

1. Repository root with README, compose, docs, evidence and scripts visible.
2. App target A status page showing two synthetic records and hash prefix.
3. Keycloak realm overview without usernames, credentials or admin URLs.
4. Terminal acceptance summary with all positive/negative booleans true.
5. Encrypted Restic snapshot/check receipt with repository identifiers cropped.
6. Target A stopped, followed by target B ready.
7. Side-by-side source/target count and complete SHA-256 match.
8. Final Docker project state empty and reserved listeners absent.
9. GitHub and GitLab anonymous repository pages at the same commit.
10. Machine-readable `summary.json` with the honest false fields visible.

## Original concept scenes

All must carry `CONCEPT IMAGE` in the edit, never “actual installation”.

1. Bright compact business equipment room with a small rack and two mini
   servers—credible, tidy and attainable, not a hyperscale data centre.
2. Close-up of two compact target devices labelled A and B with a protected
   backup device between them.
3. An operator reviewing a simple exit checklist on a laptop beside the rack;
   no legible credentials or brand UI.
4. Encrypted backup represented as a sealed data case moving from A to B.
5. A small team learning from source and architecture diagrams in a meeting
   room; realistic Norwegian/European small-business setting.
6. Old and new hardware modules side by side to support “upgrade parts, not
   everything”.
7. Optional future-authentication table with a generic security key and reader;
   no fingerprint card presented as selected, ordered or tested.
8. Clean handover scene: source, runbook and recovery checklist delivered to a
   company team.

Use calm daylight, dark green/slate accents and documentary realism. Avoid
glowing holograms, impossible cables, biometric close-ups or brand imitation.
